One-line safety warning label that should come printed on every human being,
entered in the make.fun bounty **Warning Label for Humans**.

> WARNING: Do not shake. This human is held together by caffeine, spite, and a playlist they refuse to share.

## Run

```sh
node main.ts
# writes entry.txt (107 chars) to ./out
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory. Deterministic: no network,
no clock, no randomness — run it twice and the output is byte-identical.
